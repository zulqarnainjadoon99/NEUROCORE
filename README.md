# NEUROCORE – Intelligence Engine

**An AI-Assisted Workflow Analysis and Risk Monitoring Platform**

NEUROCORE is a web-based intelligence workspace designed to help users analyze workflows, identify potential risks, improve operational processes, and maintain analysis records.

## Key Features

- **Dashboard:** Overview of workflow activity and statistics.
- **Workflow Analysis:** Analyze workflows and identify improvement opportunities.
- **AI Integration:** Connect with the Gemini AI engine through a secure Cloudflare Worker.
- **IT Video Center:** Access selected IT learning resources.
- **Reports:** View saved analysis records and export reports as CSV.
- **Risk Monitoring:** Review identified workflow risks.
- **Bilingual Interface:** English and Urdu language support.
- **Responsive Design:** Designed for desktop and mobile screens.
- **Local Storage:** Save analysis records in the browser.

## Technology Stack

- HTML5
- CSS3
- JavaScript
- Google Gemini API
- Cloudflare Workers
- Browser Local Storage

## Project Architecture

The frontend is built with HTML, CSS, and JavaScript. AI requests are sent through a Cloudflare Worker, which securely handles communication with the Gemini API.

The API key is stored as a Cloudflare secret and is not included in the public source code.
